Ambit — Architecture & Code Map

Ambit helps a freelancer compare a client message against their contract deliverables before agreeing to unpaid extra work. The app separates reading from counting: an optional server route splits custom text into candidate requests, a deterministic quote verifier checks that every quoted clause is an exact substring of the contract, and a pure TypeScript math engine computes every hour total, dollar total, count-based bar percentage, and the three-sentence client reply.

How One Action Flows Through the Code

Action traced: clicking Analyze message or flipping Request #4 from Unclear to Extra.

3-Stop Reference Route

This reference route traces how a request status change recalculates the bill, bar, and client reply without calling the AI again.

  1. Stop 1 — UI Event Handler: src/app/page.tsx → search for function handleSetFlag and calculateAmbitSummary(items, rateStr, usingSample). When you click Extra on Request #4, handleSetFlag calls flipItemStatus so an Unclear item keeps its stored 2 h default (or falls back to 2 h if hours were zero).
  2. Stop 2 — Pure Quote Verifier & Math Engine: src/lib/ambit.ts → search for export function verifyClauseQuotes and export function calculateAmbitSummary. verifyClauseQuotes normalizes whitespace and curly quotes on both sides before checking exact substring containment; calculateAmbitSummary sums only Extra hours (15 h → 17 h), multiplies by the clamped hourly rate ($375 → $425), sizes the scope bar by request count (20% / 80% / 0%), and builds the 3-sentence reply via buildChangeOrderReply.
  3. Stop 3 — Optional Server AI Boundary: src/app/api/analyze/route.ts → search for export async function POST and validateAiItems. Reads ANTHROPIC_API_KEY and ANTHROPIC_MODEL on the server only, enforces MAX_INPUT_CHARS = 6000, caps output at 8 items with only the 4 allowed fields (requestText, clauseQuote, status, hours), and runs verifyClauseQuotes before returning.

To Change This, Start Here

  • Change the built-in sample contract, WhatsApp message, or default $25/hr rate: edit SAMPLE_CONTRACT, SAMPLE_MESSAGE, SAMPLE_HOURLY_RATE, and SAMPLE_ITEMS in src/lib/sample.ts.
  • Change the default hours when an Unclear request is flipped to Extra: edit DEFAULT_UNCLEAR_HOURS = 2 in src/lib/ambit.ts.
  • Change the 3-sentence client reply wording: edit buildChangeOrderReply in src/lib/ambit.ts and run npm test to verify the unit test suite in test/ambit.test.ts.
  • Change light/dark color tokens: edit .am-root and .am-root[data-theme="dark"] in src/app/globals.css.

A Practice to Reuse

Separate AI classification from deterministic verification and math. In devpost/spec.md (Risk #1 and Risk #4), we identified two failure modes common in LLM apps: the model might paraphrase or invent a contract clause, or a prompt injection inside the client message might try to manipulate dollar totals. Instead of trusting model output directly, validateAiItems in src/lib/ambit.ts strips every field except requestText, clauseQuote, status, and hours (tested in test/ambit.test.ts Subtest #7), and verifyClauseQuotes checks word-for-word substring containment against the contract text after normalizing whitespace and curly quotes (tested in Subtest #5). Any quote that fails is forced to Unclear with "No matching clause found", and all dollar math happens in pure TypeScript.

How to run the app and tests locally (snapshot notes)
